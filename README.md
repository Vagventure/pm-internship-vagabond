# PM Internship Portal

A web-based portal designed to streamline the application and management process for Product Management internships.

## Getting Started

1. **Clone the repository:**
    ```bash
    git clone https://github.com/sezallagwal/pm-internship-portal.git
    cd pm-internship-portal
    ```

2. **Install dependencies:**
    ```bash
    npm install
    ```

4. **Run the development server:**
    ```bash
    npm run dev
    ```
